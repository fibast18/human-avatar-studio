# Human Avatar Studio — Release history

## v1.1.0 — Hybrid Automatic AI

Cumulative enhancement of v1.0.0. Added:

- AI Center with automatic, cloud, local, and rule-only modes.
- Opt-in local WebGPU/WebLLM Qwen2.5 0.5B model loading, progress display, unload.
- Secure Worker endpoint for Gemini 2.5 Flash-Lite free-tier API; secrets remain off GitHub and out of the client.
- Worker input bounds, exact allowed origin, token auth, strict missing-binding failure, native per-IP rate-limiting hook.
- Local chat history for multi-turn context; transparent response-source indicator.
- More conservative command intent routing to avoid treating open-ended questions as body movement instructions.
- v1.1.0 service-worker cache and manifest metadata.

Preserved: Maya/Alex, textured GLB models, expressive sculpt, existing 23 actions and 12 moods, orbit camera, voice recognition/TTS, sound, preference toggles, legacy localStorage keys/history, responsive iPhone UI and developer credit.

## v1.0.0 — Initial GitHub Pages app

Two avatars, motion command engine, facial expression controls, microphone and spoken responses, three.js scene, installable web app, device-local settings and recent history.
