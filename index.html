Animation commands always work without AI. Automatic mode tries the cloud if configured, then the local model if enabled, then command-only replies. AI-generated text never executes avatar actions.

📱 Option B — On-device AI

WebLLM with a compact 4-bit Qwen2.5 0.5B model. Requires WebGPU and a large first-time download (roughly 1 GB of runtime memory, plus model files). The browser may evict its cached model. Test iPhone Safari compatibility before relying on it offline.

Local AI not loaded.

Local AI is opt-in and starts only after you choose to download it. Model files and WebLLM script are fetched from their public hosts, not from Gemini.

☁️ Option C — Secure Gemini cloud AI

Deploy the supplied Cloudflare Worker first. Enter the Worker URL and your own randomly generated Worker access token below. Never paste a Gemini API key here or into GitHub.

Worker token stays in this browser's local storage. It is not a Gemini key. Only use on a personally controlled device; clearing website data removes it. Cloud prompts leave your device and may be processed under Google's free-tier data terms.

Response source: rule-based commands until an AI engine is used.
